# Contributing

Thanks for helping. A few things to know first.

- **This repository is generated.** It is synced from the main Styloviz repository on every release, so a pull request is applied there by a maintainer and arrives here with the next sync. Your authorship is kept in the commit.
- **Bugs:** open an issue with the package, its version, your Angular version and the smallest code that shows the problem.
- **Questions and ideas:** the [community Discussions](https://github.com/styloviz/community/discussions).
- **Before a pull request:** `npm run build` and `npm test` must pass. A fix comes with a spec that fails without it.
- **Security reports:** do not open an issue; see https://styloviz.dev/security.
